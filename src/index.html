            Making a places file

            Any AI chat can write it for you. Nothing to install.
            1. Copy the prompt below into an AI chat, then paste your list of places underneath. A name is enough; add the metro station and exit gate if you know them.
            2. Save the reply as a file ending in .json: copy the JSON block into Notepad and save it with UTF-8 encoding, or download it from the chat.
            3. Import it with the button here, or drop the file onto the map. A report lists every place that came in and the station it sits at; places you already have are left untouched and marked already exists.
            Prompt

            Fields the app understands: name, station, gate, lat, lon, category, tags, notes, source. Only name and station are needed; distances and categories are worked out on import. A CSV with the same column names works too.
